# AI100 development and run workspace

AI100 uses `D:\Projects\MechoFly` as its canonical development and run
directory. It tracks a named branch from
`https://github.com/yaelkroy/MechoFly.git`; `main` is the default. The
machine-local profile selects recording-matched MechoFly Prism and automatic capacity
evaluation.

## Prerequisite

Install stable Rust with Cargo from <https://rustup.rs/> if `cargo --version`
is not available. The repository requires Rust 1.95 or newer. The setup script
does not silently install toolchains or drivers.

## Initial setup or safe synchronization

Run from Windows PowerShell 5.1:

```powershell
Set-ExecutionPolicy -Scope Process Bypass
.\tools\Setup-AI100-MechoFly.ps1 -Launch
```

The setup script:

1. clones the selected branch when the target is absent or empty;
2. otherwise requires the canonical origin and a clean worktree, then switches
   safely from an explicitly fetched origin ref and permits only a fast-forward
   to that ref without relying on implicit upstream tracking (including
   checkouts originally cloned with `--single-branch`);
3. proves local branch, `HEAD`, and tree exactly match GitHub before and after
   the build;
4. writes `%LOCALAPPDATA%\MechoFly\runtime-profile.json` with Prism,
   `compute = auto`, branch, commit, tree, executable SHA-256, and
   `live_hardware_authority = NONE`;
5. verifies tree identity, builds the release Rust executable, and runs the
   deterministic safety self-test;
6. verifies CPU-without-GPU support, startup/reevaluation controls, all eight
   global-hotkey mappings and fallback, Firefly Prism identity, anatomical
   context, learning isolation, skin defaults, and unchanged live state;
7. removes only recognized shortcuts from the previous fly application; and
8. creates current-user Start, recording-matched Original, comprehensive Brain
   Lab, Sync, Capture Evidence, Stop, and Emergency Stop shortcuts.

Omit `-Launch` for synchronization and verification only.

For a review branch, name it explicitly. An optional full 40-character commit
pin makes setup fail if the GitHub branch no longer points to the reviewed
commit:

```powershell
.\tools\Setup-AI100-MechoFly.ps1 `
    -Branch 'feat/transparent-pet-dark-brainlab-v3' `
    -ExpectedCommit '<full GitHub commit SHA>' `
    -Launch
```

## Guarded recovery from the pre-branch ZIP installation

`tools/Recover-AI100-ExactCandidate.ps1` handles the one diagnosed AI100 state
where the reviewed Rust tree was staged on top of legacy `main` instead of
being checked out as its GitHub commit. Recovery is intentionally narrow: the
legacy HEAD and complete staged-tree identity must match the recorded values,
and any unstaged or untracked file causes refusal.

Before synchronization, the script preserves the staged tree as a named Git
stash, a local backup branch, and a standalone Git bundle in Downloads. It then
runs the hash-pinned setup, exact-source evidence collector, ZIP verification,
and optional launch. It never uses `git reset --hard` or `git clean`.

Recovery is resumable. If preservation succeeded but setup or evidence capture
stopped later, running the same pinned recovery again verifies the clean base or
exact target plus the backup branch and complete Downloads bundle, then resumes
without creating a second preservation. It can also fast-forward a clean prior
candidate only when that commit is a proven ancestor on the exact target branch.
An unrelated, divergent, dirty, or wrong-branch checkout is refused.

Git can leave the fetched candidate staged on the old branch when an explicit
`switch --track` fails in a checkout originally cloned with `--single-branch`.
Recovery recognizes that interrupted state only when its index tree resolves to
the pinned prior review commit, the branch and base HEAD still match, there are
no unstaged or untracked files, and the original backup branch and bundle verify
first. It then preserves the generated residue in its own branch and bundle
before continuing; no reset, clean, or irreversible discard is used.

## Exact runtime identity

Setup writes `artifacts\ai100-source-identity.json`. Start checks that receipt
offline before every launch and refuses dirty source, a branch/commit/tree
mismatch, or an executable hash mismatch. The Sync shortcut refreshes the
selected GitHub branch, fast-forwards, rebuilds, self-tests, and replaces the
receipt. It never resets or overwrites a dirty worktree.

To prove AI100 still matches the current GitHub branch without launching:

```powershell
.\tools\Assert-AI100-SourceIdentity.ps1 -RefreshRemote
```

## Runtime and design evidence

Quit any existing MechoFly process, then run:

```powershell
.\tools\Capture-AI100-Evidence.ps1
```

The collector refuses a GitHub mismatch, records the exact source and EXE
identity, captures the Firefly transparent pet plus Auto/GPU-capable and forced
CPU Neural Observatory cases, records application logs and capacity context,
and creates one `UPLOAD_MechoFly_AI100_ExactSource_Design_*.zip` in Downloads.
The runtime cases inject bounded Groom and Loom messages through the installed
pet window and wait for modeled selection before capture, so the archive shows
animated behavior and its neural receipt instead of idle-only windows.
Screenshots are cropped to MechoFly windows with 16 pixels of context; the full
desktop is not captured. It stops only processes it started.

Recovery downloads the collector from the exact target commit, verifies its
raw SHA-256 and Windows PowerShell 5.1 syntax, and executes that pinned temporary
copy. It does not hash the Windows working-tree bytes, because Git may
legitimately materialize LF-authored PowerShell files with CRLF line endings.

## Runtime behavior

Every launch benchmarks CPU and any compute-capable GPU. AMD, Intel, and NVIDIA
are treated by capability and measured performance, not brand. With no usable
GPU, CPU is selected automatically. Brain Lab can repeat calibration; that
operation creates a new session if capacity selection changes.

## Refusal conditions

Setup stops without replacing content if the target is a nonempty
non-repository directory, origin is unexpected, the worktree is dirty, the
selected branch or commit cannot be resolved exactly, or fast-forward is
impossible. It does not delete project directories, reset source, rewrite
history, configure WSL, install drivers, or grant live hardware authority.

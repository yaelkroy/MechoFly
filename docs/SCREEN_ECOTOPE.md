# Screen Ecotope work-mode boundary

The Screen Ecotope is a deterministic, local, Drosophila-inspired virtual environment for the desktop companion. It separates ecological state from presentation safety.

## Implemented in the first vertical slice

- A generated fermentation source remains fixed during its environmental epoch.
- A bounded deterministic virtual plume changes cue encounters without moving source truth.
- A 32 by 18 interpretable belief map records generated reward observations, value, uncertainty, visits, and reward recency.
- Hunger, fatigue, approach, local search, exploration, refuge seeking, alert, escape, quiet wake, and rest are represented as derived ecological state.
- The cursor threat proxy uses radial closing speed and estimated time to contact. Mere cursor proximity is not treated as looming.
- Generated habitat art remains hidden in Work Mode.
- Untagged UI content never creates food, water, or refuge resources.
- The pet remains in the Windows topmost group while neural windows are open.
- Ordinary Work Mode mouse interactions pass through the pet. Holding Alt explicitly arms direct pet interaction.

## Evidence classifications

| Quantity | Classification |
|---|---|
| Neural activation and spikes | Modeled neural evidence |
| Ecological mode and motivation | Derived ecological state |
| Belief values and uncertainty | Modeled software spatial learning |
| Fermentation source and plume | Authored virtual stimulus |
| Cursor approach score | Virtual cursor-approach proxy |
| Fly drawing and habitat styling | Authored presentation |
| Topmost or click-through relocation | Presentation safety behavior |

The implementation does not claim measured neural activity, measured odor, measured humidity, a complete biological brain, or validated whole-animal ethology. Generated resources are controlled software stimuli. Learning never mutates the imported connectome.

## Privacy boundary

The first vertical slice does not capture screenshots, OCR, window titles, URLs, file names, document contents, clipboard contents, or typed text. UI content has no ecological semantics by default.

## Work Mode contract

- no focus activation;
- no ordinary click interception;
- no neural-window Z-order demotion;
- no visible generated habitat by default;
- no sound or notification;
- no automatic interpretation of desktop content as a biological resource.
